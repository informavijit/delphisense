# Changelog

## 0.1.0 — Initial release

- Four commands: Analyze File / Folder / Project (.dpr, .dpk) / Workspace
- Built-in rules: unusedUses, longMethod, emptyExceptFinally, deadCodeAfterExit, deepNesting, todoComment, longLine
- Inline diagnostics (Problems panel + squiggles)
- Professional, self-contained HTML report with quality score, category breakdown, per-file summary, and detailed findings — downloadable via Save Report As
- Workspace-defined custom pattern rules via `.delphisense/rules.json`
