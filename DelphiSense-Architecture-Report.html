Executive Summary

DelphiSense is a high-performance, lightweight code review and static analysis extension for Visual Studio Code, optimized specifically for Embarcadero Delphi and Object Pascal projects (`.pas`, `.dpr`, `.dpk`, `.pp`, `.inc`).

Traditional language servers for Pascal frequently require matching compiler binaries, configured library paths, and complex project setup. DelphiSense bypasses these friction points through a resilient, single-pass line-oriented scanner that extracts structural code metrics and flags vulnerabilities across any version of Delphi or FreePascal.

  • Zero Language Server Overhead: Requires no Delphi IDE install, `.dproj` parsing, or external toolchains.
  • Decoupled Core Engine: Built with standard TypeScript (`src/engine/`) without VS Code runtime dependencies, enabling future CLI or CI/CD integration.
  • String & Comment Neutralization: Algorithmic blanking guarantees zero false-positive matches inside string literals or multiline comments.
  • Professional HTML Reports: Generates self-contained, offline-safe code review reports with dynamic Quality Scoring.

Detailed Component Breakdown

4.1. Extension Entry Point (src/extension.ts)

Handles extension activation, registers user commands, monitors workspace settings, coordinates background progress notifications (`vscode.window.withProgress`), and manages webview preview tabs.

4.2. Target Resolution Heuristics (src/target.ts)

Maps high-level target selections into verified file path lists. Filters noise directories (`.git`, `node_modules`, `__history`, `__recovery`, `bin`, `obj`) and resolves `.dpr`/`.dpk` `uses` clauses into actual disk units.

4.3. Resilient Structural Analyzer (src/engine/structuralAnalyzer.ts)

Constructs a lightweight structural representation (`ParsedUnit`) for each file. Features a line-oriented scanner that neutralizes strings and comments while leaving line and column coordinates intact: 

// Example of blanking logic in action:
// Raw Source:
procedure Foo; begin ShowMessage('Exit; inside string'); end;

// Blanked Representation passed to rules:
procedure Foo; begin ShowMessage('                    '); end;
4.5. Built-in Detection Rules Specification
Rule ID Category Severity Detection Logic & Strategy
unusedUses Code Smell Hint Checks whether short unit names declared in uses clauses appear elsewhere in the file.
longMethod Code Smell Warning Flags procedures/functions whose body line count exceeds delphisense.longMethod.maxLines (default: 60).
deepNesting Code Smell Warning Tracks begin/case/if/try nesting depth per routine body against threshold (default: 4).
emptyExceptFinally Bug Warning Detects empty except...end blocks (swallowed exceptions) or empty finally blocks.
deadCodeAfterExit Bug Warning Flags unreachable statements immediately following Exit, raise, or Abort.
longLine Code Smell Hint Flags lines exceeding delphisense.maxLineLength.max (default: 120 chars).
todoComment Documentation Hint Extracts TODO, FIXME, HACK, or XXX comment annotations.
4.6. Custom Rules Declarative Framework (src/engine/customRules.ts)

Teams can define custom regex rules without writing TypeScript code via .delphisense/rules.json: 

{
  "rules": [
    {
      "id": "noHardcodedConnStr",
      "pattern": "Password\\s*=",
      "message": "Possible hardcoded password in a connection string.",
      "severity": "error"
    }
  ]
}

Comprehensive Feature List

5.1. Multi-Target Analysis
  • Analyze Current File: Instant verification of the active editor file or context menu target.
  • Analyze Folder: Recursive scan of selected directory trees with automated noise folder exclusion.
  • Analyze Project (.dpr/.dpk): Smart resolution of project main files and referenced units.
  • Analyze Workspace: Full scan across open workspace folders.
5.2. VS Code UI Integrations
  • Problems Panel Integration: Live warnings, errors, and hints with line jump navigation.
  • Explorer Context Menus: Right-click options on `.pas`, `.dpr`, `.dpk`, and folders.
  • Webview Review Panel: In-editor tab showing styled quality score ring, category distribution, and findings.
  • Export Affordance: One-click "Save Report As..." export option to preserve HTML review reports.
6

Non-Functional & Architectural Strengths

  • Zero Runtime Dependencies: Uses standard Node.js built-ins (`fs`, `path`, `os`) with a package footprint of ~34 KB.
  • Decoupled Core Architecture: Pure TypeScript engine isolated from VS Code APIs for CLI wrapper capability.
  • High Throughput: Scans tens of thousands of lines of code in under 100 milliseconds.
  • 100% Offline Safe: HTML reports require zero external fonts, JS frameworks, or internet calls.
